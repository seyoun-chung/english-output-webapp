# Chapter 3 Pass 3 — Complete

## Goal

사용자가 Chapter 3을 교재 Source 범위 안에서 처음부터 끝까지 다시 꺼내고,
도움 장치를 줄인 상태로 모든 필수 학습을 완료한다.

## Entry and preservation

- 완료된 Pass 2에서만 사용자가 명시적으로 Pass 3을 시작한다.
- Pass 1과 Pass 2의 진행, 자기평가, Writing, 완료 시각을 변경하지 않는다.
- version 4 migration은 version 1–3 저장 기록을 보존한다.

## Required flow

1. My Story Full Recall
2. Real Conversations — Play A, Play B, Full Dialogue
3. Output Practice — No Hint
4. Grammar Focus — studied
5. What About You? — 사용자 답변 한 개 완료
6. Weekly Writing — Pass 3 새 draft 한 개 완료
7. Chapter Review — Chapter 3 Source 고정 세트 완료
8. 명시적 `Finish Pass 3`

완료는 정답률이나 발음 점수가 아니라 각 영역을 실제로 수행하고 자기평가한 기록으로 판단한다.
Pronunciation은 별도 영역이라 완료를 막지 않는다.

## Source and review decisions

- 새 영어 Target이나 예문을 만들지 않는다.
- No Hint는 기존 Chapter 3 Source 문장을 힌트 없이 재사용한다.
- Grammar와 What About You의 표시를 Pass 3에서 Required로 전환한다.
- Chapter Review는 검증된 Chapter 3 고정 12문항을 재사용한다.
- Smart Review 간격, 전역 문제 수, Pass 4+ 무작위 정책은 여기서 확정하지 않는다.

## Acceptance

- Pass 2 완료 전 Pass 3을 만들 수 없다.
- Pass 3 기록은 Pass 1·2와 분리되어 저장된다.
- 7개 영역 중 하나라도 빠지면 완료할 수 없다.
- No Hint는 이전 Exact 평가만으로 완료되지 않는다.
- 완료 전·후 새로고침 복원이 된다.
- 데스크톱과 390px/320px 반응형 화면에서 주요 CTA와 이동이 작동한다.
- Source 밖 영어 학습 문장이 추가되지 않는다.
